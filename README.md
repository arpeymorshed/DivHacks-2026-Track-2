# aartee.

Your personal rent agent. Built for DivHacks 2026.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Pages

- **Dashboard** — Dues, wallet balance, rules, activity feed
- **Unit chat** — Group chat with roommates and agents (Photon fallback)
- **Chat bubble** (bottom-right) — 1-on-1 with your agent
- **Notifications** (bell icon) — Click any notification for full details
- **Demo pill** (bottom-left) — Guardian Demo + Building Console for the pitch

## Switching tenants

Use the picker in the top-right corner to switch between Maya (paid), Jordan (late), and Priya (due).
